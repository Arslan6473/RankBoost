To optimize content for a keyword, choose one primary keyword per page, place it in the title, the main heading and the first 100 words, and then use it naturally along with two or three related variations throughout the text. Aim for natural usage, commonly around 1 to 2 percent density, rather than a fixed number of repetitions. The goal is to make the page's topic unmistakable without making it awkward to read.

Keyword optimization is one of the oldest parts of SEO, and it still matters because search engines need clear signals about what a page covers. What has changed is that repetition alone no longer works. Modern search understands meaning, so well-placed keywords and strong topical coverage beat stuffing every time.

## Why keyword optimization still matters

A page that never mentions the phrase people search for makes the search engine's job harder. A page that mentions it in every sentence makes the reader's job harder. Good optimization sits between those extremes. It confirms relevance in the places search engines and readers look first, then lets the content do the rest.

If you are new to the topic, our [on-page SEO guide](/blog/on-page-seo-guide) covers the wider set of signals keywords sit alongside.

## Where to place your target keyword

| Location | Why it matters | Tip |
| --- | --- | --- |
| Title tag | Strong relevance signal and shown in search results | Put the keyword near the start |
| H1 heading | Confirms the page topic to readers | Can match or vary the title |
| First 100 words | Tells readers they are in the right place | Answer the query early |
| One or two subheadings | Reinforces structure | Use variations, not exact repeats |
| Meta description | Can be bolded in results when it matches the query | Write for clicks, not just keywords |
| URL slug | Short, readable relevance signal | Keep it brief and hyphenated |

## Step by step: optimizing a page by hand

**1. Confirm the search intent.** Is the searcher looking to learn, compare or buy? The [Search Intent Analyzer](/tools/search-intent-analyzer) can help you classify a query. Content that matches intent performs better than content that simply repeats a keyword.

**2. Write the title and H1 first.** Keep the title roughly 50 to 60 characters, a commonly recommended range for avoiding truncation. Check it with the [SEO Title Analyzer](/tools/seo-title-analyzer).

**3. Answer the query in the opening.** Use the keyword in the first 100 words, ideally in a sentence that directly answers the question.

**4. Add semantic variations.** For "search engine optimization," related terms might include "SEO," "rankings," "organic traffic" and "search results." These help cover the topic fully.

**5. Measure density.** Run the finished draft through the [Keyword Density Checker](/tools/keyword-density). If the primary keyword is far above about 2 percent, replace some instances with variations or pronouns. Our guide on [what keyword density is](/blog/what-is-keyword-density) explains the numbers.

**6. Write the meta description.** Summarize the page's value in roughly 150 to 160 characters and include the keyword once. The [AI Meta Tag Generator](/tools/ai-meta-generator) can draft a starting point.

## Common keyword optimization mistakes

- **Targeting several primary keywords on one page.** Pick one primary topic per page and support it with related terms.
- **Keyword stuffing.** Repeating the exact phrase unnaturally hurts readability and can be treated as spam.
- **Forcing exact-match phrases.** "Best running shoes cheap" should be written as natural English, not pasted in as is.
- **Ignoring the rest of the page.** Keywords help search engines find the topic; depth and quality earn the ranking.
- **Optimizing once and forgetting.** Revisit pages as search results and your content change.

## FAQ

### How many times should a keyword appear in an article?

There is no ideal count. Use it in the key locations above, then let it appear wherever it reads naturally. For most articles, that lands in roughly the 1 to 2 percent density range.

### Should I use the exact keyword or a variation in headings?

Use the exact keyword in the H1 and vary it in subheadings. Variations make the page read better and help cover related searches.

### Can I optimize an existing page for a new keyword?

Yes, if the new keyword matches what the page is actually about. Update the title, H1, opening paragraph and meta description, then expand the content to cover the new angle fully.

### Do long-tail keywords need the same optimization?

The same principles apply, but long-tail phrases are often questions. Using them as subheadings and answering them directly underneath is usually the most natural approach.

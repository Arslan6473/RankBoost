To reverse text, flip it so the last character comes first: "Hello, world!" becomes "!dlrow ,olleH". The free [Reverse Text tool](/tools/reverse-text) does this instantly, and a second mode reverses the order of words instead, turning "one two three" into "three two one" while keeping each word spelled normally.

Below, we'll look at both modes, what reversed text is good for, and a few edge cases worth knowing.

## Two ways to reverse text

"Reverse text" can mean two different things, and the tool supports both:

| Mode | Input | Output |
| --- | --- | --- |
| Characters | Hello, world! | !dlrow ,olleH |
| Words | the quick brown fox | fox brown quick the |

**Character mode** reverses every character in the text, including spaces and punctuation. The whole string reads backwards.

**Word mode** keeps each word intact but reverses their order. Spacing between words is carried along, so the result still reads as separate words.

## What backwards text is useful for

Reversed text is mostly a fun utility, but it has some practical uses too:

- **Puzzles and games.** Backwards clues, scavenger hunts and riddles are a classic.
- **Mirror writing.** Reversed text is a starting point for mirror-style designs and art. Note that reversing characters changes their order, not their shape, so letters aren't flipped visually.
- **Social posts and usernames.** Backwards phrases can make a post or handle stand out.
- **Checking palindromes.** Reverse a word or phrase and compare it to the original. If they match (ignoring spaces and punctuation), it's a palindrome.
- **Testing software.** Developers use reversed strings to check how apps, fonts and layouts handle unusual input, and how text rendering copes with characters in an unexpected order.
- **Rephrasing drafts.** Reversing word order can help you spot when a sentence would read more naturally with its parts rearranged.

## Things to know before you reverse

### Multi-line text reverses as a whole

In character mode, the entire text is reversed, including line breaks. That means the last line ends up first, and each line's characters are also backwards. In word mode, word order is reversed across the whole text too, so words can move between lines. If you only want to flip the order of lines, use [Reverse Lines](/tools/reverse-lines) instead.

### Some emoji and combined characters can split

Certain emoji, such as flags, skin-tone variants and family emoji, are built from several code points joined together. Reversing them by code point can separate the pieces, so they may display differently afterward. The same can happen with letters that use separate combining accent marks. If something looks off, check those characters by hand.

### Punctuation moves with the text

In character mode, a period at the end of a sentence moves to the start. In word mode, punctuation stays attached to the word it was next to, so "Hello, world!" becomes "world! Hello,". Tidy the punctuation afterward if you need clean output.

### Reversed text isn't secure

Backwards text is easy for anyone to read back. Don't use it to hide passwords or sensitive information.

## FAQ

### How do I check if a word is a palindrome?

Reverse it in character mode and compare. "level" reversed is still "level", so it's a palindrome. For phrases, remove spaces and punctuation and ignore capitalization before comparing.

### Can I reverse each word but keep the word order?

Not directly with this tool. Character mode reverses the whole string, which also reverses word order. To spell each word backwards in its original position, put each word on its own line, reverse the characters, then reverse the lines with the Reverse Lines tool.

### Does reversed text affect SEO?

Reversed text has no SEO value on its own, since search engines and readers expect normal language. Keep it for creative or testing purposes, not for page content you want to rank.

### Is there a length limit?

There's no fixed limit. Processing happens locally in your browser, so even long passages reverse quickly.

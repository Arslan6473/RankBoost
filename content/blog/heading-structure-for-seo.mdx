A good heading structure for SEO uses one H1 that states the page's main topic, H2s for the major sections, and H3 to H6 only to nest subtopics inside those sections, without skipping levels. Think of headings as a table of contents: anyone scanning them should understand what the page covers and how it's organized.

This guide covers the rules of heading hierarchy, common mistakes, and how to audit any page with the free [Heading Structure Checker](/tools/heading-checker).

## What heading tags do

HTML offers six heading levels, from `h1` (most important) to `h6` (least). In Markdown, they're written with one to six hash marks. Headings serve three audiences:

- **Readers** skim headings to decide whether a page answers their question and to jump to the part they need.
- **Assistive technology** users often navigate pages by heading, so a logical hierarchy is an accessibility requirement, not just a style choice.
- **Search engines** use headings as one of several signals to understand the topics and structure of a page.

## Why heading hierarchy matters for SEO

Headings aren't a magic ranking lever, but a clear structure supports SEO in practical ways. It makes long content easier to read, which keeps visitors engaged. It helps search engines identify distinct sections that could answer specific queries, sometimes as featured snippets. And it naturally encourages you to cover subtopics thoroughly, which improves topical depth.

## Heading structure rules

### Use one H1 per page

The H1 is the page's main headline and should describe its primary topic, usually including the primary keyword. Google has said multiple H1s won't break anything, but a single H1 keeps the outline unambiguous and is the convention most audits check for.

### Use H2s for main sections

Each H2 should introduce a major part of the page. If you read only the H1 and the H2s, the page's argument or structure should be clear.

### Nest H3 to H6 logically

An H3 belongs under an H2, an H4 under an H3, and so on. Most pages rarely need anything deeper than H3 or H4.

### Don't skip levels

Jumping from an H2 straight to an H4 breaks the outline. Moving back up, for example from an H4 to a new H2, is fine.

### Don't use headings for styling

If you want large or bold text that isn't a section title, use CSS instead of a heading tag. Headings should only mark real sections.

## Best practices for SEO headings

- **Write descriptive headings.** "Pricing" is fine for navigation, but "How Much Does a Website Audit Cost" tells readers and search engines more.
- **Include keywords naturally.** Use your primary keyword in the H1 and related terms in some H2s. Don't force the exact phrase into every heading.
- **Keep headings concise.** A heading is a signpost, not a paragraph.
- **Match the promise of your title.** Your H1 and title tag can differ in wording but should describe the same topic. Test title drafts with the [SEO Title Analyzer](/tools/seo-title-analyzer).
- **Turn question headings into FAQs.** If a section is a list of questions, consider marking it up with the [FAQ Schema Generator](/tools/faq-generator).

## Common heading mistakes

| Mistake | How it happens | Fix |
| --- | --- | --- |
| No H1 | Theme uses the logo or a styled div as the headline | Make the page title an H1 |
| Several H1s | Widgets or sidebars use H1 tags | Change extra H1s to H2 or plain text |
| Skipped levels | Headings chosen by font size | Pick levels by hierarchy, style with CSS |
| Headings in footers and sidebars | Template components | Use non-heading elements for widget titles |

## FAQ

### Do heading tags in the navigation or footer count?

Yes. Any heading tag in the HTML is part of the page's outline. If your template uses headings for menus or footer columns, they appear in audits and in screen reader navigation.

### Should every section have the same number of subheadings?

No. Add subheadings where they help readers. A short section may need none, while a detailed one may need several H3s.

### Can I start a page with an H2?

It's better not to. Without an H1, the page lacks a clear top-level heading. Many themes add the H1 automatically from the post title, so check the rendered page rather than just your editor.

### Is heading order more important than keyword use?

They serve different purposes. A logical order helps people and assistive technology follow the page, while keywords signal topic. Get the structure right first, then refine the wording.
